# 🌸 Student Task Management System

A Full Stack Web Application developed using **Flask, MongoDB, HTML, CSS, and JavaScript** to help students manage their academic tasks efficiently.

---

## 📌 Features

- 👤 User Registration & Login (JWT Authentication)
- ➕ Add New Tasks
- ✏️ Edit Existing Tasks
- 🗑️ Delete Tasks
- ✅ Mark Tasks as Completed
- 🔍 Search Tasks
- ⭐ Favorite Tasks
- 📂 Filter Tasks (All, Pending, Completed, Favorites)
- ↕️ Sort Tasks (Priority, Due Date, A-Z)
- 📊 Dashboard with Task Statistics
- 📈 Progress Bar
- 📊 Task Analytics Chart
- 📊 Priority Analytics Chart
- 📅 Calendar View
- 📄 Export Tasks to PDF
- 🌙 Dark Mode
- 📱 Responsive Design
- 🔔 Due Today & Overdue Task Notifications
- 🔊 overdue notification sound

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone <your-github-repository-link>
```

### 2. Install Python packages

```bash
pip install -r requirements.txt
```

### 3. Start MongoDB

Ensure MongoDB is running on your system.

### 4. Run the Flask server

```bash
python app.py
```

### 5. Open the Frontend

Run the frontend using Live Server or open the HTML files in your browser.
